# Omar Ahmed Keshk Personal Website

Personal academic website of Omar Ahmed Keshk, nuclear engineer and researcher.

**Website:** https://omar-keshk.github.io

Static site (HTML, CSS, JavaScript) hosted on GitHub Pages.

## Pages

- `index.html`: summary, education, research themes, highlights, history of Alexandria
- `research.html`: research projects
- `outputs.html`: publications, theses, presentations
- `history.html`: History of Alexandria (nine eras)
- `gallery.html`: photos and milestones
- `contact.html`: email, GitHub, LinkedIn

## Files to add

`style.css`, `script.js` and simple placeholder icons (`nav-icon.png`, favicons) are already in `assets/`. Replace the icons with your own if you like.

```text
Omar_Cv.pdf
assets/profile.jpg, alexandria.png (university logo)
assets/alexandria-qaitbay.jpg, alexandria-library.jpg
assets/gallery/ (jinr.jpg, ayss-2025.jpg, graduation-2025.jpg, ennra-2025.jpg,
                 michigan-2024.jpg, scholarship-2024.jpg, ugrf-2023.jpg, planetarium.jpg)
```

Missing images are hidden automatically, but the pages look best with all of them.

## Updating

Edit the text inside each HTML file and commit to `main`. GitHub Pages redeploys within a few minutes.
